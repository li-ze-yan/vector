## 核心数据类型（Data Types）

### 数值类型

```sql
-- 整数
SMALLINT          -- 2 字节，-32768 ~ 32767
INTEGER / INT     -- 4 字节，-2^31 ~ 2^31-1
BIGINT            -- 8 字节，-2^63 ~ 2^63-1

-- 自增整数（底层是序列 SEQUENCE）
SMALLSERIAL       -- 2 字节自增
SERIAL            -- 4 字节自增
BIGSERIAL         -- 8 字节自增

-- 精确小数（金融场景推荐）
NUMERIC(precision, scale)   -- 例：NUMERIC(10, 2) 表示最多 10 位，2 位小数
DECIMAL(precision, scale)   -- 与 NUMERIC 等价

-- 浮点数（科学计算，存在精度误差）
REAL              -- 4 字节单精度
DOUBLE PRECISION  -- 8 字节双精度
```

### 字符类型

```sql
CHAR(n)           -- 定长，不足则右补空格，很少使用
VARCHAR(n)        -- 变长，最多 n 个字符
TEXT              -- 变长，无长度限制（推荐，性能与 VARCHAR 相同）
```

> PostgreSQL 中 `TEXT` 与 `VARCHAR` 性能完全一致，无需为性能而选 `CHAR`。

### 布尔类型

```sql
BOOLEAN           -- TRUE / FALSE / NULL
-- 可接受的输入：true/false, yes/no, on/off, 1/0
```

### 日期与时间类型

```sql
DATE              -- 仅日期，如 '2024-01-15'
TIME              -- 仅时间，如 '14:30:00'
TIMESTAMP         -- 日期+时间，不含时区
TIMESTAMPTZ       -- 日期+时间+时区（推荐，内部存储为 UTC）
INTERVAL          -- 时间间隔，如 INTERVAL '3 days 2 hours'
```

```sql
-- 常用时间函数
SELECT NOW();                            -- 当前时间（含时区）
SELECT CURRENT_DATE;                     -- 当前日期
SELECT NOW() - INTERVAL '7 days';        -- 7 天前
SELECT DATE_TRUNC('month', NOW());       -- 本月第一天
SELECT EXTRACT(YEAR FROM NOW());         -- 提取年份
```

### JSON 类型

```sql
JSON              -- 存储原始 JSON 文本，每次查询重新解析
JSONB             -- 二进制格式存储，支持索引，查询更快（推荐）
```

```sql
-- JSONB 示例
CREATE TABLE events (
  id      BIGSERIAL PRIMARY KEY,
  payload JSONB NOT NULL
);

INSERT INTO events (payload)
VALUES ('{"type": "login", "user_id": 42, "tags": ["web", "mobile"]}');

-- 按键查询
SELECT payload->>'type' FROM events;               -- 返回文本
SELECT payload->'user_id' FROM events;             -- 返回 JSONB

-- 数组元素
SELECT payload->'tags'->0 FROM events;             -- 返回 "web"

-- 条件过滤
SELECT * FROM events WHERE payload @> '{"type": "login"}';

-- 建索引
CREATE INDEX idx_events_payload ON events USING GIN (payload);
```

### 数组类型

```sql
-- 任意类型都可以变成数组
CREATE TABLE products (
  id    SERIAL PRIMARY KEY,
  tags  TEXT[],
  scores INT[]
);

INSERT INTO products (tags, scores) VALUES
  (ARRAY['electronics', 'sale'], ARRAY[95, 88, 72]);

-- 查询包含某元素的行
SELECT * FROM products WHERE 'sale' = ANY(tags);

-- 数组操作
SELECT tags[1] FROM products;                     -- 下标从 1 开始
SELECT array_length(scores, 1) FROM products;     -- 数组长度
SELECT unnest(tags) FROM products;                -- 展开为多行
```

### UUID 类型

```sql
UUID              -- 128 位，标准格式 xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

-- 启用扩展（生成 UUID v4）
CREATE EXTENSION IF NOT EXISTS "pgcrypto";

CREATE TABLE sessions (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id    BIGINT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 其他常用类型

```sql
BYTEA             -- 二进制数据（图片、文件等）
INET              -- IPv4/IPv6 地址，支持网络运算
CIDR              -- 网络地址段
MACADDR           -- MAC 地址
TSVECTOR          -- 全文检索向量
TSQUERY           -- 全文检索查询
```

## 列约束（Column Constraints）

### PRIMARY KEY

主键约束：唯一 + 非空，每张表只能有一个主键，但可以是复合主键。

```sql
-- 单列主键
CREATE TABLE users (
  id BIGSERIAL PRIMARY KEY
);

-- 复合主键（表级约束）
CREATE TABLE order_items (
  order_id   BIGINT,
  product_id BIGINT,
  quantity   INT NOT NULL,
  PRIMARY KEY (order_id, product_id)
);
```

### NOT NULL

列值不允许为 `NULL`，是最基础也最常用的约束。

```sql
CREATE TABLE users (
  id       BIGSERIAL PRIMARY KEY,
  username TEXT NOT NULL,
  email    TEXT NOT NULL
);

-- 事后添加
ALTER TABLE users ALTER COLUMN email SET NOT NULL;
-- 移除
ALTER TABLE users ALTER COLUMN email DROP NOT NULL;
```

### UNIQUE

唯一约束：该列（或列组合）在表内不允许重复，允许多个 `NULL`（`NULL != NULL`）。

```sql
-- 列级
CREATE TABLE users (
  email TEXT UNIQUE
);

-- 命名约束（推荐，便于后续删除）
CREATE TABLE users (
  email TEXT,
  CONSTRAINT uq_users_email UNIQUE (email)
);

-- 复合唯一
CREATE TABLE memberships (
  user_id  BIGINT,
  group_id BIGINT,
  CONSTRAINT uq_membership UNIQUE (user_id, group_id)
);
```

### DEFAULT

为列指定默认值，插入时若未提供该列则自动填充。

```sql
CREATE TABLE posts (
  id         BIGSERIAL PRIMARY KEY,
  status     TEXT        NOT NULL DEFAULT 'draft',
  view_count INT         NOT NULL DEFAULT 0,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

### CHECK

自定义校验表达式，插入或更新时若表达式为假则报错。

```sql
CREATE TABLE products (
  id    BIGSERIAL PRIMARY KEY,
  price NUMERIC(10, 2) CHECK (price >= 0),
  stock INT            CHECK (stock >= 0),
  -- 命名 CHECK，便于错误定位
  CONSTRAINT chk_price_positive CHECK (price >= 0)
);

-- 跨列 CHECK
CREATE TABLE events (
  starts_at TIMESTAMPTZ NOT NULL,
  ends_at   TIMESTAMPTZ NOT NULL,
  CONSTRAINT chk_event_duration CHECK (ends_at > starts_at)
);
```

### FOREIGN KEY

外键约束：引用另一张表的主键或唯一键，保证引用完整性。

```sql
CREATE TABLE posts (
  id      BIGSERIAL PRIMARY KEY,
  user_id BIGINT NOT NULL
    REFERENCES users(id)
    ON DELETE CASCADE      -- 父行删除时级联删除子行
    ON UPDATE CASCADE,     -- 父行主键更新时级联更新
  title   TEXT NOT NULL
);

-- 常见 ON DELETE 策略
-- CASCADE     父行删除 → 子行一并删除
-- SET NULL    父行删除 → 子行外键置 NULL（列须允许 NULL）
-- SET DEFAULT 父行删除 → 子行外键置默认值
-- RESTRICT    父行有子行时拒绝删除（默认）
-- NO ACTION   与 RESTRICT 类似，延迟到事务结束检查
```

### GENERATED（生成列）

列值由表达式自动计算，不需要手动插入。

```sql
-- STORED：物理存储计算结果
CREATE TABLE orders (
  quantity   INT            NOT NULL,
  unit_price NUMERIC(10, 2) NOT NULL,
  total      NUMERIC(10, 2) GENERATED ALWAYS AS (quantity * unit_price) STORED
);
```

### 约束管理

```sql
-- 查看表的所有约束
SELECT conname, contype, pg_get_constraintdef(oid)
FROM pg_constraint
WHERE conrelid = 'app.users'::regclass;

-- 删除约束
ALTER TABLE users DROP CONSTRAINT uq_users_email;

-- 禁用 / 启用外键检查（批量导入时临时禁用）
ALTER TABLE posts DISABLE TRIGGER ALL;
-- ... 批量插入 ...
ALTER TABLE posts ENABLE TRIGGER ALL;
```
